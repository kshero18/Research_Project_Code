Call centre operations are inherently complex due to fluctuating customer demands, varying query complexities, and resource constraints. Optimising these systems requires models that can not only handle stochasticity but also adapt in real-time to changing workloads. This report presents an end-to-end framework that integrates classical simulation techniques for checking the assumptions and uses modern reinforcement learning techniques and compares them to address the dual goals of reducing customer waiting times and minimising agent overtime costs. Building on earlier foundational work, which explored First-Come-First- Serve (FCFS) and Longest-Waiting-Customer (LWC) strategies under Markov Decision Process (MDP) assumptions, this study advances the research by validating these assumptions on realworld data and identifying significant departures from exponential and Poisson distributions. A comprehensive data preprocessing pipeline was implemented to clean, standardise, and engineer temporal features for modelling. Statistical tests, including the Kolmogorov-Smirnov test, Q-Q plots, and autocorrelation analysis, revealed that empirical call data exhibits high variance and temporal dependencies not captured by traditional queueing theory. To overcome the rigidity of precomputed MDP policies, a custom Gym-compatible environment was created and trained using Proximal Policy Optimisation (PPO). The PPO model was evaluated against FCFS and LWC policies across multiple data regimessynthetic, semi-synthetic, and empirical demonstrating superior performance in managing queue lengths, reducing customer rejections, and optimising cumulative rewards. PPO policies exhibited adaptability by learning optimal dispatch decisions based on observed state transitions rather than relying on idealised transition probabilities. Overall, this report presents a practical, data-driven approach to call centre optimisation that bridges theoretical models and real-world operations. The findings highlight the benefits of reinforcement learning in environments with stochastic and non-Markovian behaviours, paving the way for intelligent, scalable resource allocation systems.
